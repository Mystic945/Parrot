Signal path

What happens between the key and the text

Five stages, all of them on your own CPU. The longest one is the model, and it is already resident in memory before you ever press the key.

01

Key down

A global shortcut fires whether or not Parrot has focus.

Ctrl + Alt + Space
02

Capture

Your chosen microphone streams into a buffer, mixed down to mono as it arrives.

44.1 / 48 kHz in
03

Resample

Window-averaged down to the only rate the model accepts.

16 kHz mono f32
04

Transcribe

Whisper runs locally through whisper.cpp, across your CPU cores.

ggml · greedy decode
05

Paste

Text goes to the clipboard, one synthetic paste fires, your clipboard is put back.

restores prior contents
Why local

The recording never becomes someone else’s data

Dictation is the most sensitive thing you type

Passwords go in a manager, but everything else — the medical note, the salary figure, the message you rewrote four times — goes through your keyboard. A cloud dictation service turns all of it into a request body on someone else’s server. Parrot never opens a socket: pull your network cable and it works exactly the same.

It keeps working on a plane

No connection, no sign-in, no service to be down or discontinued.

Nothing accumulates

Audio lives in memory for the length of one utterance and is discarded. No history is uploaded, no account exists to leak.

Pick your trade between speed and accuracy

Downloaded from inside the app on first run, then kept on disk. Switch at any time; the English-only models are more accurate than the multilingual one at the same size.

First run

Two minutes, most of it a download

00

Windows will warn you, and it is right to

Parrot is not code-signed — a certificate costs a few hundred dollars a year. SmartScreen shows “Windows protected your PC”; the button you want is behind More info → Run anyway. If you would rather not take that on trust, build it yourself from source.

01

Install

A few seconds, no administrator rights, and Parrot appears in your Start menu and system tray.

02

Choose a speech model

The first launch has no model yet. Pick one from the list and it downloads with a progress bar — 142 MB for the default.

03

Check your microphone

Parrot follows your Windows default, but some machines ship with a default input that records pure silence. If nothing is transcribed, pick a different device under Diagnostics — the status line reports the measured level in dBFS so you can tell silence from quiet.

04

Hold, speak, release

Press Ctrl Alt Space anywhere, say your piece, and let go. Rebind it to whatever you like in settings.

Requirements

What it needs from your machine

Operating system
Windows 10 or 11, 64-bit. macOS and Linux builds are not available yet.
Processor
Any modern x86-64 CPU. No graphics card is used — transcription is CPU-only.
Disk
About 20 MB installed, plus 75–466 MB for whichever speech model you choose.
WebView2
Used for the settings window. Already present on Windows 11 and current Windows 10; the installer adds it if missing.
Microphone
Any input device Windows can see. Bluetooth headsets work but sound worse, as they do everywhere.
Network
Only to download the app and its model. Never used afterwards.
